Найдём любую вещь по Казахстану

Введите что угодно. Покажем миллионы вариантов: где продают, какая цена лучше, новая вещь или б/у и в каком она состоянии.

Скачать для Windows Открыть на GitHub

Замените «твой-ник» на свой аккаунт GitHub после загрузки релиза.

Демо-режим: варианты и цены моделируются по вашему запросу, чтобы показать, как выглядят результаты. Ссылки ведут на реальный поиск у продавца.

Не ищем алкоголь, наркотики, товары 18+ и другие запрещённые вещи.

Как установить

1. Скачайте найдём-kz-setup.exe из раздела Releases
2. Запустите установщик
3. Введите название вещи и нажмите «Найти»
Проект с открытым кодом. Перед покупкой проверьте цену и наличие на сайте продавца.
